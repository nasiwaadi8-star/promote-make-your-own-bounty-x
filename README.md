This repository hands in a public post on X for make.fun's bounty
[Promote make.fun's make-your-own-bounty post on X](https://make.fun/bounty/post-x-promote-make-your-own-bounty-01).
The post quotes make.fun's make-your-own-bounty announcement post, carries a
photo, and includes the entrant's play code for this bounty in its text. The
post's address lives in `POST.json` at the root of this repository, and
`main.ts` copies `POST.json` into the output directory for the grader.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
